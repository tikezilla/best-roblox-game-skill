# Workflow: Competition Polish Audit

Use this after a playable competition or school-project vertical slice exists.

## Audit Categories

### Idea and Originality

- The purpose can be stated in one sentence.
- The target user is specific.
- The Roblox interaction is necessary or meaningfully helpful.
- The project has an original mechanic, visualization, or perspective.

### Implementation

- The core loop works without manual setup during a demo.
- The project starts cleanly in playtest.
- Console output has no unresolved errors.
- Three technical systems can be explained by the student.
- Source code and app access can be provided if requested.

### UX and Design

- The first screen tells the player what to do.
- The interface is readable on desktop and mobile.
- Every action gives immediate feedback.
- Failure states explain what happened and how to recover.
- Motion, sound, and visuals support the concept.

### Demo Readiness

- The demo path fits in three minutes.
- The app name, purpose, audience, tools, and functionality are clear.
- The technical challenge and solution are rehearsable.
- AI use, third-party assets, and student contributions are documented.

## Output

Return a prioritized punch list:

```text
Must fix before submission:
Should improve if time allows:
Demo talking points:

```
